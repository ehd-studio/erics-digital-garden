A self contained block of code that can be continuously run.

---
*str()* - evaluates input to a string
*int()* - evaluates input to an int. Cannot evaluate values that are floats to an integer and will round down.
*float()* - evaluates input to a float. 
*round(value 1, value 2)* - rounds float values to the nearest even integer. *Value 2* can be used to set the number of values it must round to.
